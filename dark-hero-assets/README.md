# Dark Hero Sprite Pack

Pixel-art hero assets for Astrocade.

Style: gothic dungeon crawler / dark fantasy action RPG.

Files:

- `hero-idle.png`: 6 frames, 192x32, transparent PNG
- `hero-run.png`: 6 frames, 192x32, transparent PNG
- `hero-attack.png`: 6 frames, 192x32, transparent PNG
- `hero-hurt.png`: 6 frames, 192x32, transparent PNG
- `hero-death.png`: 6 frames, 192x32, transparent PNG
- `hero-preview.png`: stacked preview only, 192x160

Astrocade prompt:

```text
I uploaded five sprite sheets for the player character: hero-idle.png, hero-run.png, hero-attack.png, hero-hurt.png, and hero-death.png.

Replace the current square player with this gothic dark-fantasy pixel hero.
Each sprite sheet has 6 frames in a single horizontal row. Each frame is 32x32 pixels.

Use hero-idle when the player is not moving.
Use hero-run when the player is moving.
Use hero-attack when the hero sword attack triggers.
Use hero-hurt when the player takes damage.
Use hero-death when the player dies.

Keep the same gameplay hitbox, movement speed, collision behavior, and camera behavior as the current square player.
Do not make the player larger than the original hitbox; only change the visual sprite.
```
